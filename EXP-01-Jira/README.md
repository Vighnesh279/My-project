# EXP-01 - Agile SDLC Using Jira

## Aim

To understand and implement Agile Software Development Life Cycle (SDLC) practices using Jira with the Scrum framework.

## Tools Used

- Jira
- GitHub
- Scrum Board
- GitHub-Jira integration

## Project

Project Name: Agile DevOps Demo

Project Key: DEVOPS

## Epic

User Authentication

## User Stories

1. User Registration
2. User Login
3. Password Reset

## Sprint

Sprint 1

The sprint was planned with a defined goal and duration. User stories were selected from the product backlog and tracked through the Scrum Board.

## Jira-GitHub Integration

The User Login story was tracked as:

DEVOPS-3 - User Login

A GitHub branch was created for the Jira issue:

DEVOPS-3-jira-integration

The corresponding GitHub commit and pull request were linked with Jira.

## Scrum Workflow

The issues were tracked through the Scrum workflow using statuses such as:

To Do -> In Progress -> Done

## Reports

The experiment also included Jira sprint reporting, including:

- Burndown
- Velocity

## Result

Agile project management was implemented using Jira Scrum, including backlog management, sprint planning, issue tracking, GitHub integration, and sprint reporting.
