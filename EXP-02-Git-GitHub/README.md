# EXP-02 - Git and GitHub Version Control



## Aim



To understand and implement fundamental Git and GitHub version control operations for collaborative software development.



## Tools Used



- Git

- GitHub

- Command Prompt



## Git Operations



The experiment covered:



- Git configuration

- Repository initialization

- Checking repository status

- Creating and staging files

- Creating commits

- Viewing commit history

- Creating feature branches

- Switching between branches

- Merging branches

- Creating and resolving a merge conflict

- Connecting the local repository to GitHub

- Pushing changes to GitHub

- Pulling changes from the remote repository



## Branching



A feature branch was created to demonstrate independent development before merging changes into the main branch.



## Merge Conflict



A merge conflict was deliberately created by modifying the same line in different branches.



The conflict was resolved manually and the resolved version was committed.



## GitHub



The local repository was connected to a GitHub remote repository and changes were pushed to GitHub.
